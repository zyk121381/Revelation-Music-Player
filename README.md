# ✔ [Revelation Music Player](https://github.com/zyk121381/Revelation-Music-Player)

一个使用 React 和 Tailwind CSS 构建的现代响应式音乐播放器，具有播放列表管理、歌词支持和沉浸式 UI 设计。

## ⭐功能

- **歌词支持：** 自动同步歌词显示，提供沉浸式的听歌体验。
- **歌词翻译：** 支持「原文 || 译文」双语歌词，可随时开关译文显示。
- **响应式设计：** 跨平台适配，无论设备大小都能提供流畅的使用体验。
- **移动端双页视图：** 黑胶唱机页与沉浸式歌词页，支持左右滑动切换。
- **沉浸式 UI：** 现代简约的设计，专注于音乐播放体验。
- **音乐频谱：** 桌面端实时显示音频频谱，增强视觉效果。
- **播放列表管理：** 支持歌曲的添加、删除和排序。
- **隐藏歌曲：** 歌曲可标记为隐藏，需管理员密码解锁后才会显示并参与播放。
- **曲库加密：** 全部歌曲直链经加盐混淆加密后存放，源码中不暴露任何明文链接。
- **曲库明文助手：** 二级密码验证后可在线编辑曲库明文 JSON，并一键重新加密。
- **播放控制：** 包括播放、暂停、上一曲、下一曲、播放速度和进度条控制。
- **音量控制：** 支持音量调整（默认初始音量为70%）。
- **URL 参数播放：** 支持通过 URL 参数播放自定义音乐和内置音乐。
- ~**JSON API：** 用于获取实时音乐数据的API接口。~（已于1.0.3版本移除）

## ⚡快速入门 / 📄文档

### 部署

**环境：** Node.js

1. 安装依赖项：`npm install`
2. 在 `vite.config.ts` 文件中 `allowedHosts` 的中配置部署网站的域名，并按需修改端口（注意：服务器部署网站时开放的端口必须与 `vite.config.ts` 中配置的端口一致）
3. 按需完成「安全配置」与「歌曲操作」（详见下方两节）
4. 运行应用程序：`npm run dev`

### 歌曲操作

歌曲明文统一维护在项目根目录的 `songs.raw.json`，修改后使用同步脚本重新加密并写入 `constants.ts`。
**请勿手动编辑 `constants.ts`**，运行同步脚本会整体覆盖该文件。

1. 在 `songs.raw.json` 中按标准JSON格式添加歌曲对象。

   - `"name"`：歌曲名称（字符串）
   - `"artist"`：歌手（字符串）
   - `"url"`：音频文件的 URL（字符串）
   - `"cover"`：封面图片的 URL（字符串）
   - `"lrc"`：歌词文件的 URL（字符串）
   - `"hide"`：是否为隐藏歌曲（选填，填入 `true` 或 `"true"` 时，该歌曲默认不在列表中显示，需管理员解锁）
2. 运行同步命令，脚本会自动加密全部歌曲并覆盖写入 `constants.ts`：

   ```
   npm run sync:songs
   ```

   （等价于 `node scripts/syncVault.js`）
3. ~访问 `/list` 可获取音乐详情列表~（已于1.0.3版本移除）

### 歌词与翻译格式

歌词文件（`.lrc`）支持以下写法，播放器会自动解析并排序：

- 无译文：`[00:12.50]歌词内容`
- 含译文：`[00:12.50]歌词原文 || 歌词译文`（使用两个竖线 `||` 分隔原文与译文）
- 一行多个时间戳：`[00:12.50][01:20.00]歌词内容`（同一句歌词会被复制到每个时间戳）

只有当前歌曲确实包含译文时，歌词区才会出现翻译开关按钮。

### 安全配置（部署前必做）

仓库中的配置为**占位值**，正式使用前必须替换为自己的配置，否则加密曲库与管理功能无法正常工作：

1. **加密盐值**

   修改 `songVault.ts` 中的 `VAULT_SALT`，并同步修改 `scripts/syncVault.js` 中的 `VAULT_SALT`。
   **两处盐值必须完全一致**，否则前端无法解码密文，播放列表会显示为空。
   修改盐值后需重新运行 `npm run sync:songs` 生成新的密文。

   生成一个随机盐值（复制到上述两个文件）：

   ```
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

2. **管理员密码哈希**

   替换 `security.ts` 中的两个哈希值（代码中只保存不可逆哈希，不保存明文密码）：

   - `LEVEL_1_PASSWORD_HASH`：一级密码，用于在播放列表中**显示隐藏歌曲**
   - `LEVEL_2_PASSWORD_HASH`：二级密码，用于进入**曲库明文维护与加密助手**

   支持 64 位 SHA-256 或 32 位 MD5（按长度自动识别）。生成 SHA-256 哈希：

   ```
   node -e "console.log(require('crypto').createHash('sha256').update('你的密码').digest('hex'))"
   ```

3. **不要提交明文曲库**

   `songs.raw.json` 中包含全部音频与歌词直链，建议将其加入 `.gitignore`，仅提交占位示例数据，以免抵消曲库加密的作用。

### 管理员功能

#### 1. 显示隐藏歌曲

1. 打开播放列表，点击右上角「显示隐藏」
2. 输入**一级管理员密码**，验证通过后隐藏曲目会显示在列表中，并带「隐藏」标签，同时参与顺序播放与随机播放
3. 此时按钮变为「已解锁」，点击即可重新锁定并隐藏私密歌曲
4. 解锁状态**不会写入本地缓存**，刷新页面后自动恢复锁定

#### 2. 曲库明文维护与加密助手

1. 先完成**一级解锁**，播放列表头部会出现「曲库助手」按钮
2. 点击后输入**二级管理员密码**进入（该助手包含全部直链信息，每次打开都需重新验证）
3. 在编辑区可直接修改曲库明文 JSON，并提供以下操作：

   - 「格式化对齐」：自动排版 JSON
   - 「复制明文 JSON」：复制到剪贴板，可粘贴进 `songs.raw.json`
   - 「下载 raw.json」：下载为 `songs.raw.json` 保存到项目根目录
   - 「一键生成加密密文并复制」：生成最新密文并复制，可粘贴回 `constants.ts`
   - 「锁定退出」：重新锁定二级保护
4. 改动生效有两种方式，任选其一：

   - **直接替换密文（最快）**：在助手中改好明文 → 点击「一键生成加密密文并复制」 → 用复制到的密文整体替换 `constants.ts` 中 `ENCRYPTED_SONG_VAULT` 的值，即 `export const ENCRYPTED_SONG_VAULT = "粘贴新的密文";`
   - **本地同步**：在助手中改好明文 → 点击「下载 raw.json」或「复制明文 JSON」覆盖项目根目录的 `songs.raw.json` → 本地运行 `npm run sync:songs`

   **注意：** 助手生成密文使用的是 `songVault.ts` 中的盐值，本地脚本使用的是 `scripts/syncVault.js` 中的盐值，两种方式只有在两处盐值相同时才可互换。

### 歌词翻译的开关

- 桌面端：歌词区右下角的悬浮「译 OFF / 译 ON」按钮
- 移动端：黑胶唱机页底部工具条中的「译 OFF / 译 ON」按钮
- 每首歌曲默认**关闭**译文显示，切换歌曲时会自动重置为关闭状态

### URL 参数播放

#### 1. 播放自定义音乐

通过在 URL 中添加参数来播放自定义音乐，播放器会自动将歌曲添加到播放列表顶部并默认开启单曲循环模式。

**支持的参数：**

- `name`：歌曲名称（必填）
- `audio`：音频文件的直链 URL（必填）
- `artist`：歌手名称（选填，默认为 "Unknown Artist"）
- `cover`：封面图片的 URL（选填，默认使用随机占位图）
- `lrc`：歌词文件的 URL（选填）

**示例 URL：**

```
https://项目地址/?name=SongName&artist=ArtistName&audio=SongUrl&cover=CoverUrl&lrc=LrcUrl
```

#### 2. 播放特定的内置音乐

通过 `player` 参数直接播放曲库（`songs.raw.json` / `constants.ts`）中已配置的歌曲。

**使用方法：**

```
https://项目地址/?player=歌曲名称
```

播放器会自动：

- 在内置的音乐列表中找到这首歌
- 将这首歌移动到播放列表的顶部并作为当前歌曲
- 将播放模式设置为单曲循环

**注意：**

- 如果传入的 `player` 名称在列表中不存在，播放器将按照默认顺序加载第一首歌曲。
- 被标记为隐藏（`hide`）且未解锁的歌曲，无法通过 `player` 参数播放。

**重要提示：** 由于浏览器限制，以上两种参数方式都不会自动播放，会显示弹窗提醒，需要用户手动点击播放按钮开始播放。
